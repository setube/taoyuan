## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 核心体验 | **戴夫式渐进经营**：前期玩家亲自当主厨、跑堂；定制菜单、备货、按客服务；中后期招聘员工、培训、排班，玩家处理大事，但**随时可亲自下场** |
| 经济定位 | 中后期**第二现金流**：消化酒坊/烹饪/酒窖产出，不宜与商圈「直接卖货」完全重复 |
| 社交定位 | v1 绑定 **村民好感**（来客 + 专属宴席），不做 v1 村民入职 |
| 技术风格 | 文字版经营，**标准亲自营业**有逐步操作；与现有 **日结 `useEndDay`**、时段 `advanceTime`、仓库/酒窖 store 衔接 |

## 2. 与现有系统关系

```text
农场 / 酒坊（酿酒批量↑） / 烹饪
        ↓ 库存（背包 + 仓库）
酒窖（陈酿增值）
        ↓
前厅酒肆（待客、定价、员工、好感）
        ↓
铜钱 / 口碑 / NPC 好感 / 专属订单奖励
```

| 已有模块 | 酒肆中的角色 |
|----------|----------------|
| 酒坊 `wine_workshop` | 酒类货源；**需改为熔炉式批量（见 §8）** |
| 烹饪 + **新 `cooking` 技能** | 热菜、小食货源；技能等级/专精影响品质、售价、酒肆主厨（§5.3） |
| 农舍 Lv3 + **酒窖** `useHomeStore` | 陈酿酒 → **窖藏招牌槽** 高价/好感加成 |
| 仓库 `useWarehouseStore` | 备货、营业扣料（背包+仓库） |
| 商圈 `market` | 原料行情、客流偏好（待数值对齐，见待决） |
| NPC `useNpcStore` | 来客频率、喜好菜、专属宴席 |
| 节日 / 社区包 | v2+ 旺季活动、排名（v1 可预留字段） |
| 钱庄 | v2+ 扩建周转（v1 可不接） |
| 日结 `useEndDay` | 默认「当晚自动营业」演算入口 |

**原则**：酒肆 = **前店后窖** 的变现与叙事舞台，不是第二个万物铺。

## 3. 已确认决策总表

| # | 议题 | 结论 |
|---|------|------|
| 1 | 经营范式 | 戴夫式：先全能打工 → 再招人管理；玩家可一直亲自参与 |
| 2 | 时间结构 | **C 混合（当日二选一）**：要么白天 **亲自值班**（全日营业在此结算），要么睡前配置 **日结自动**；**同一天不可叠加** |
| 3 | NPC v1 | **① 来客 + 喜好菜**；**② 好感阶段专属宴席/订单** |
| 3b | NPC v2（不做 v1） | 招聘村民当员工；配偶酒肆专属线 |
| 4 | 建筑位置 | **B 农舍扩建「前厅酒肆」**（家园/农舍面板入口，前店后窖） |
| 5 | 亲自营业 v1 深度 | **标准档**：开铺检查 → 来客列表（含 NPC 喜好）→ 按客后厨+上菜 → 结账（小费/好感） |
| 6 | 员工 v1 | **帮厨 + 跑堂**；**纯系统随机 NPC**（随机名、随机属性） |
| 7 | 员工属性 | **厨艺 / 情商 / 智商 / 体力** 四维 + **付费培训** |
| 8 | 菜单 v1 | **D**：分类槽位（含 **鲜果槽**）+ **酒窖窖藏招牌槽**（陈酿联动） |
| 9 | 酿酒效率 | 酒坊 **全部配方**（含酒类、米醋等）改为熔炉机制：单次 **1～3** 份原料，产出 1:1（按配方 inputQuantity 倍率） |
| 10 | 营业模式互斥 | 当日 **亲自值班** 与 **日结自动** **二选一**；选亲自则日结不再演算酒肆 |
| 11 | 扩建解锁 | **仅农舍 Lv3**（`farmhouseLevel >= 3`）；**不需**主线/社区包；另付铜钱 + 材料一次性扩建前厅 |
| 12 | 酒坊批量范围 | `wine_workshop` 下 **所有配方一并改**（酒、醋、酱缸若同机待实现时核对 machineType） |
| 13 | 定价 | **区间限价**，锚定 `items.sellPrice`；指导价倍率 **3.0+**（见 §8.3）；玩家 **0.85×～1.40×** 指导价 |
| 14 | 鲜果 + 温室 | 菜单 **鲜果槽**；**当季** 3.0×，**反季** 4.8× 且好卖；温室反季供给见 §8.4 |
| 15 | 酒肆等级 | **5 级**扩建表（§4.1）；与酒窖节奏对齐 |
| 16 | 烹饪技能 | 新增第 6 技能 **`cooking`**；Lv5/Lv10 专精见 §5.3；酒肆读技能等级 §6.1 |
| 17 | 负面事件 | **v1 不做**（无罢工/随机事故）；仅保留上错菜轻量口碑扣减 |
| 18 | 亲自值班体力 | 与玩家共用体力条，上限 **`playerStore.maxStamina`**（§5.2） |

| 项 | 规则 |
|----|------|
| 入口 UI | **农舍 / 家园**（`CottageView` 或 `HomeView`）新增「前厅酒肆」区块，与酒窖并列 |
| 解锁条件 | **农舍 Lv3 酒窖宅院**（`farmhouseLevel >= 3`）+ 铜钱 + 材料；**无**主线/社区包前置 |
| 未解锁 | 仅酒窖陈酿，无经营面板 |
| 存档 | 新 `useTavernStore`（或扩 `useHomeStore`）serialize；旧档缺省为未扩建 |

### 4.1 酒肆扩建等级表（已确认）

解锁 **农舍 Lv3** 后可一次性建造 **酒肆 Lv1**；之后消耗铜钱 + 材料逐级升级（数据写入 `data/tavern.ts` → `TAVERN_UPGRADES`）。

| 酒肆等级 | 名称 | 座位 | 菜单槽（酒/热菜/小食/鲜果/窖藏） | 员工上限（帮厨+跑堂） | 日结基础来客 | 升级费用（铜钱） | 主要材料 |
|----------|------|------|----------------------------------|----------------------|--------------|------------------|----------|
| **1** | 前厅酒肆 | 4 | 1 / 1 / 1 / 1 / 1 | 0 + 0 | 6 | **80000**（初建） | 木×150、铁锭×8 |
| **2** | 前厅·贰 | 6 | 1 / 2 / 1 / 1 / 1 | 1 + 1 | 9 | 35000 | 木×120、铁锭×5 |
| **3** | 前厅·叁 | 8 | 2 / 2 / 2 / 2 / 1 | 1 + 1 | 12 | 70000 | 木×200、金锭×8 |
| **4** | 前厅·肆 | 10 | 2 / 3 / 2 / 2 / 2 | 2 + 1 | 15 | 120000 | 木×300、金锭×15 |
| **5** | 前厅·伍 | 12 | 3 / 3 / 2 / 2 / 2 | 2 + 2 | 18 | 180000 | 木×400、铱锭×5 |

- **Lv1** 仅玩家亲自经营；**Lv2** 起可招聘首位帮厨与跑堂。

- 费用锚定酒窖扩建（3万～15万）略高一档，体现前厅为后期现金流建筑。
- 口碑、节日、NPC 好感在此基础上叠乘来客，不写入上表。

## 5. 一日时间结构（C 混合 · 当日二选一）

每日营业方式 **只能选一种**（`tavernStore.todayMode: 'manual' | 'auto' | 'closed'`）：

| 模式 | 何时选定 | 结算时机 |
|------|----------|----------|
| **亲自值班** | 白天进入酒肆并开启「今日亲自营业」 | 当轮流程结束或玩家打烊时 **当场结算**；日结 **不再** 演算酒肆 |
| **日结自动** | 睡前配置菜单/排班（默认若未亲自则走此模式） | **`useEndDay`** 演算当晚营业 |
| **今日打烊** | 任意时刻可选 | 无收入，不扣库存 |

### 5.1 日结自动营业

玩家在睡前（或日结前）配置：

- 今日菜单（槽位上架）
- 员工排班（帮厨/跑堂是否在岗）
- 确认模式为 **auto**（若白天已选 manual 则不可再切 auto）

**日结时** `useEndDay` 调用酒肆演算：

- 来客数、营业额、工资支出、口碑变动
- 消耗仓库/酒窖库存
- NPC 随机来访、喜好命中 → 好感微增
- 收益 **低于** 亲自值班（鼓励深度玩但不惩罚轻量玩家）

### 5.2 白天亲自值班

- 选定后当日锁定为 **manual**，日结跳过酒肆章节
- 进入酒肆面板消耗 **游戏时段 + 体力**（与钓鱼/下矿类似 `advanceTime`）
- 执行 **§6 标准营业流程**
- 额外：更高单价/小费、NPC 专属剧情客

**体力规则（已确认）**：

- 与全局 **`playerStore.stamina`** 共用，**不另设酒肆体力池**
- 单日亲自值班可消耗体力上限 = 当日 **`playerStore.maxStamina`**（含仙桃、金丹等加成后的动态上限）
- 各步骤体力消耗建议：接客 **4**、后厨制作 **8**、上菜 **5**、结账 **3**（`getStaminaReduction('cooking')` 可减烹饪相关步骤；§6.1 减制作耗时，不额外减免体力）
- 体力 ≤ 5（`isExhausted`）时强制提示打烊或改由员工接手（若已雇人）；未雇人则只能结束亲自营业
- 打烊后未消耗体力不额外扣罚

### 5.3 烹饪技能（配套新增 · 已确认）

游戏现仅有农耕/采集/钓鱼/挖矿/战斗五技能，**无烹饪技能树**。酒肆与烹饪统一新增 **`cooking`**，接入现有 `useSkillStore` / `PerkSelectDialog` / `SkillView` 体系（对标星露 Artisan、双倍收获等专精分工）。

#### 5.3.1 基础规则

| 项 | 规则 |
|----|------|
| 等级 | 0～10，经验表复用 `EXP_TABLE`（与 `useSkillStore` 一致） |
| 经验来源 | `useCookingStore.cook()` 每成功产出 1 份 **+5** 经验（批量按份数计） |
| 每级被动 | 体力消耗 **−1%**（`getStaminaReduction('cooking')`）；烹饪时成品 **升档概率** 随等级提升 |
| 旧档兼容 | 首次加载若无 `cooking` 技能：补全 `level:0`；可选一次性迁移 `totalRecipesCooked × 5` 经验（不降级、不重复发奖） |
| 与炼金师 | 采集专精「炼金师」= 食用 **恢复 +50%**；烹饪专精「膳修」= **buff 效果**，互不替代 |

#### 5.3.2 Lv5 专精（二选一）

| ID | 名称 | 效果 | 说明 |
|----|------|------|------|
| `prep_cook` | **备料手** | 烹饪时 **20%** 概率不消耗「用量最大」的一种原料 | 量产备货、省稀有料 |
| `vendor_chef` | **市厨** | 食物（`food_*` / `category: food`）商圈售价 **+15%** | **当老板的选这个**；变现与酒肆营生线 |

#### 5.3.3 Lv10 专精（按 Lv5 分支）

**备料手分支**

| ID | 名称 | 效果 |
|----|------|------|
| `double_batch` | **双灶** | 烹饪成功 **15%** 概率额外 +1 份成品 |
| `gourmet_craft` | **匠心** | **25%** 概率烹饪成品品质再 **+1 档**（上限极品） |

**市厨分支**

| ID | 名称 | 效果 |
|----|------|------|
| `buff_chef` | **膳修** | 食用带 buff 的烹饪品：buff **效果 +30%**，**持续时段 +1** |
| `tavern_master` | **肆尊** | 酒肆亲自值班厨艺等效 **+2**、失误率 **−3%**；酒肆食物指导价 **+10%**；日结帮厨演算 **+15%** |

#### 5.3.4 四条终局 build

```text
备料手 ─┬─ 双灶   → 量产备货（酒肆原料仓）
        └─ 匠心   → 高品质宴席菜

市厨   ─┬─ 膳修   → 下矿/钓鱼前吃 buff 饭
        └─ 肆尊   → 酒肆老板流（冲经营首选）
```

#### 5.3.5 食谱门槛（渐进迁移）

- 新食谱优先用 `requiredSkill: { type: 'cooking', level: N }`
- 现有跨系门槛（农耕/钓鱼等）**保留**作「名菜」；日结 `useEndDay` 技能解锁食谱逻辑扩展 `cooking` 类型
- `achievementStore.stats.totalRecipesCooked` **保留**（厨师帽、成就），与技能经验并行

#### 5.3.6 实现触点（代码）

`types/skill.ts`（`SkillType`、`SkillPerk5/10`）· `useSkillStore` · `PerkSelectDialog.vue` · `SkillView.vue` · `CharInfoView.vue` · `useCookingStore.cook` 加经验 · `useSaveStore` 序列化 · `README.md` 技能列表补「烹饪」

## 6. v1 亲自营业 — 标准流程

一轮 ≈ 15～30 分钟游戏内时间（可配置）。

| 步骤 | 玩家操作 | 系统判定 |
|------|----------|----------|
| ① 开铺检查 | 查看菜单、库存、酒窖可取陈酿、员工体力 | 缺货菜品标红，可临时下架 |
| ② 接客 | 来客队列：普通客 + **高好感 NPC**（显示喜好图标） | 好感影响来访概率；天气/节日权重 |
| ③ 后厨 | 按订单从菜单制作：扣 **背包+仓库**（及酒窖槽位） | 玩家制作用 **§6.1 烹饪技能**；员工制作用员工 **厨艺**、**体力** |
| ④ 上菜 | 将成品对应桌位/NPC | 跑堂员工可自动完成部分普通桌；玩家优先 NPC 桌 |
| ⑤ 结账 | 收款、小费 | **情商**影响小费；喜好正确 → **好感 +N**；上错 → 口碑 **−1**（轻量，无额外负面事件） |

**日结自动模式**：不逐步执行 ②～⑤，用员工属性 + 菜单匹配度公式一次性演算。

### 6.1 酒肆中的玩家厨艺（已确认）

读取 **`skillStore.getSkill('cooking').level`**（0～10）及 §5.3 专精，不再使用 `totalRecipesCooked` 推导等级。

**亲自值班 · 玩家主厨时**：

| 效果 | 公式 |
|------|------|
| 有效等级 | `cooking.level`；若 `perk10 === 'tavern_master'` 则 **+2**（上限 10） |
| 制作耗时倍率 | `× (1 - effectiveLevel × 0.03)`，最多 **−30%** |
| 失误率（需重做） | `max(0%, 8% - effectiveLevel × 0.7%)`；`tavern_master` 再 **−3%** |
| 小费加成 | `+effectiveLevel × 2%` |

**日结自动**：帮厨空缺时用 `cooking.level` 代入帮厨厨艺；已雇帮厨则以员工为主、玩家 `cooking.level` **+10%** 封顶加成；`tavern_master` 再 **+15%** 演算收益。

**农舍 Lv1 厨房**：`farmhouseLevel >= 1` 时失误率再 **−2%**。

**肆尊售价**：酒肆菜单食物指导价 ×1.10（与 §8.3 玩家调价区间叠乘前计入指导价）。

## 7. 员工系统（v1）

### 7.1 岗位

| 岗位 | 职责 | 招聘上限（建议） |
|------|------|------------------|
| **帮厨** | 日结/亲自营业中的制作环节 | 1～2（随酒肆等级扩） |
| **跑堂** | 上菜、结账、小费 | 1～2 |

来源：**仅系统随机 NPC**（非村民）。v2 再考虑好感村民入职同一套属性模型。

### 7.2 四维属性

| 属性 | 作用 |
|------|------|
| **厨艺** | 制作速度、成品效果（售价加成、失败率、耗料） |
| **情商** | 跑堂小费倍率、满意度 |
| **智商** | **培训效率**：同样花钱培训，智商高 → 属性成长更快 |
| **体力** | 上班与每次动作消耗；过低 → 效率降、失误增；需休息/换班（日结恢复部分） |

### 7.3 招聘

- 打开招聘界面 → 生成若干候选人（**随机姓名** + **随机四维**）
- **工资**：按综合属性自动计算；**帮厨工资权重偏厨艺**，跑堂偏情商
- 雇佣后进入花名册，每日日结扣工资

### 7.4 培训

- 花钱选择培训目标属性（厨艺/情商/智商/体力之一）
- 成长量受 **智商** 加成
- 与「亲自营业」并行：培训不占用营业时段，或占用少量时段（待决）

### 7.5 与亲自营业分工

- 玩家可指定「我今日主厨 / 跑堂」
- 未覆盖的岗位由员工执行；员工体力不足时回落到玩家或降效
- 玩家**随时**可接一单亲自做（即使已雇满人）

## 8. 菜单系统（D）

### 8.1 分类槽位（固定栏位）

示例结构（数量随酒肆等级升级）：

| 槽位类型 | 说明 |
|----------|------|
| 招牌酒 | 来自酒坊产出酒类 |
| 热菜 | 烹饪食谱 |
| 冷盘 / 小食 | 烹饪或加工品 |
| **鲜果** | `category: fruit`；产季与温室规则见 §8.4 |
| （可选）汤羹 | 后续扩展 |

规则：

- 只能从**已解锁/已拥有配方**的物品池中选择 **上架/下架**
- 营业扣料：**背包 + 仓库**；窖藏槽另见下
- 缺货 → 当日该菜不可售 / 自动下架

### 8.2 窖藏招牌槽（酒窖联动）

- 独立 1～2 格（随酒窖/酒肆等级扩）
- 仅可上架 **酒窖陈酿中** 的酒（`homeStore.cellarSlots` 内 `AGEABLE_ITEMS`）
- 售价加成 = 基础价 + **酒窖已增值**（`addedValue` 或周期数换算）
- NPC 喜好可指向「某 NPC 最爱窖藏 XX 酒」

### 8.3 定价（已确认 · 倍率 3.0+）

| 品类 | 指导价公式（普通品质） | 玩家调价区间 |
|------|------------------------|--------------|
| 酒 | `floor(sellPrice × 3.0)` | 指导价 **0.85×～1.40×** |
| 热菜 | `floor(sellPrice × 3.2)` | 同上 |
| 小食/腌菜 | `floor(sellPrice × 3.0)` | 同上 |
| **鲜果·当季** | `floor(sellPrice × 3.0)` | 同上 |
| **鲜果·反季** | `floor(sellPrice × 4.8)` | 同上 |
| 窖藏招牌 | `floor((sellPrice + addedValue) × 3.2)` | 同上 |

- **高价惩罚**：售价 > 指导价 × 1.12 → 来客系数 **×0.94**
- **低价引流**：售价 < 指导价 × 0.92 → 来客 **×1.06**
- **日结自动**：各槽默认指导价；**亲自值班**：区间内逐菜调价，结账可触发小费/好感
- **宴席订单**：系统定价 ≈ 所选菜指导价合计 **×1.10～1.20**（固定，玩家不可改）
- **员工厨艺**：影响日结「实际成交率」与亲自营业制作环节，不直接改指导价上限

实现常量建议写入 `data/tavern.ts`：

```ts
TAVERN_PRICE_MULT = { wine: 3.0, dish: 3.2, snack: 3.0, fruitInSeason: 3.0, fruitOffSeason: 4.8, cellar: 3.2 }
TAVERN_PLAYER_PRICE_RANGE = { min: 0.85, max: 1.40 }
TAVERN_OFF_SEASON_DEMAND_MULT = 1.45
TAVERN_GREENHOUSE_OFF_SEASON_DEMAND_MULT = 1.50
```

### 8.4 鲜果槽与温室、产季联动（已确认）

**槽位**：酒肆 **Lv1** 鲜果 **1** 格；**Lv3+** 增至 **2** 格（见 §4.1）。

**可上架物品**：`items` 中 `category === 'fruit'`；自然产季取自 `fruitTrees.ts` 的 `fruitSeason`（`getFruitSeason(itemId)`）。

| 状态 | 指导价 | 需求/销量系数 | 说明 |
|------|--------|---------------|------|
| **当季** | `sellPrice × 3.0` | **×1.0** | 平价走量 |
| **反季** | `sellPrice × 4.8` | **×1.45** | 贵但 **卖得好** |
| **温室反季果** | 同反季指导价 | **×1.50** | 温室种出的反季供给 |

**当季 / 反季判定**：`gameStore.season === fruitSeason` → 当季，否则反季。

**温室联动**：

1. **供给**：温室无季节限制；温室收获 `category: fruit` 时标记 `fromGreenhouse: true`（及 `fruitSeason` 快照）。玩家可在非自然产季种出水果，供应酒肆鲜果槽。
2. **定价**：酒肆只看 **当前季节 vs 水果自然产季**——反季一律 **4.8×** + 高需求；温室 **不降价**（价值在于冬天能种夏天的果子并高价卖出）。
3. **当季温室果**：当前季节 = 自然产季时，按 **当季正常价**（3.0×）。
4. **v1 数据**：现有果树水果多来自果林/待拾取/蝙蝠洞，反季可先靠 **跨季库存**；温室水果收获标记与农场逻辑 **同期接入**；未接入前鲜果槽仍可用库存，按日历反季计价。
5. **UI**：反季上架显示「时鲜反季·客人愿付高价」；`fromGreenhouse` 反季果额外显示「温室供给」。

**来客偏好**：`npcTavernPrefs` 可配置 `favoriteFruit`；反季鲜果匹配时好感结算 **+10%**。

**商圈对照**：反季鲜果指导价应 **显著高于** 商圈直接卖果（`useShopStore`），体现经营溢价。

## 9. NPC 好感（v1）

### 9.1 来客 + 喜好菜

- 每位 NPC 配置 **FavoriteDrink / FavoriteDish / FavoriteFruit**（可 1～2 个 itemId）
- **好感越高**：来访概率、消费额、带同桌概率越高
- 当日菜单包含其喜好且 **正确上菜** → 结账时 **好感 +1～3**（可日上限）
- 上错菜 → 口碑 **−1**；缺货怠慢 → 该客跳过，不触发 v1 负面事件链

### 9.2 专属订单 / 宴席

- 好感达到阈值（如 4 心 / 8 心）解锁 **一次性订单**
- 内容：指定 **套餐或窖藏酒 + 几道菜**，期限 N 天，材料玩家自备
- 完成：大量铜钱 / 稀有物 / 好感 / 口碑
- UI：酒肆面板「宴席」页签 + 日志提醒

### 9.3 v2 预留

- 村民招聘为员工
- 婚后配偶帮工、节日宴剧情

### 15.1 全局视觉

| 项 | 规范 |
|----|------|
| 配色 | 墨底 `#1a1a1a`、`text-accent` 赤金强调、`text-success` 竹青、`text-danger` 朱红、`text-muted` 次要文案 |

| 图标 | `lucide-vue-next`，标题行 `:size="14"`，行内 `:size="10`～`12` |

|------|------|
